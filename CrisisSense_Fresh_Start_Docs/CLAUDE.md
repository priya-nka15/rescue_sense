# CLAUDE.md — Compatible Agent Guidance

Read `AGENTS.md` first. It is the authoritative project rulebook. If instructions conflict, follow `AGENTS.md` and ask the owner when ambiguity affects safety, data integrity, research validity, or scope.

CrisisSense is a fresh-start project. No code, data, trained model, experiment, or deployment is assumed to exist.

Key requirements:
- Preserve all four input modalities in the planned scope: text, image, audio, video.
- Start with a read-only repository/environment audit.
- Research novelty, dataset availability, licenses, labels, and evaluation suitability are not yet verified.
- Use a phase-at-a-time workflow and stop at each acceptance gate.
- Do not download large data/model files or install heavy dependencies without checking storage and getting approval.
- Do not fabricate cross-modal pairings or research results.
- Do not claim authenticity/currentness from similarity alone.
- Work on `main`; do not reset or discard user changes.
- Update `PROGRESS.md`, tests, and relevant docs with each approved phase.
